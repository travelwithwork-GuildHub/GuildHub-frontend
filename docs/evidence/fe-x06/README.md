# FE-X06 的瀏覽器證據

`node tests/e2e/board-panel.mjs`（需要 `npm run dev`）產生的；攔截的回應是腳本偽造的。**不連任何團隊共用的位址。**

```
[X06-S11] Tab 六次都留在面板內：button:返回 → button:返回 → …
[X06-S01] 第一下 Escape：詳情關、面板還在
[X06-S12] 詳情關了，焦點回到那張卡
[X06-S01] 第二下 Escape：面板關
[X06-S13] 面板關了，焦點在世界焦點錨上
```

## 這支腳本抓到的兩個真 bug（jsdom 看不到）

1. **焦點留在 `inert` 的卡上，Tab 直接跑出面板。** 開詳情之後焦點還在那張卡（在 `inert` 的列表區裡）；
   inert 的元素收不到 keydown，面板的 focus trap 接不到 Tab，焦點一路跑到標題列。
   修法：詳情掛載時把焦點放到自己身上。
2. **trap 對「焦點在容器上」的處理寫過頭。** 第一版把「焦點在 `<ul>` 上往前 Tab」也導到第一個可聚焦的元素
   （標題列的「關閉」按鈕），結果 Tab 到不了第一張卡。修法：往前走交給瀏覽器（DOM 順序的下一個就在容器裡），
   只在邊界攔。
