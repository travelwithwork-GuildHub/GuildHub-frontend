## ⚠️ 這些截圖證明什麼、不證明什麼

**證明**：元件在收到那份資料時會生成那些門、標籤上會出現名稱與在線數、
四種狀態各自長得不一樣。

回應是腳本自己攔截並偽造的（`page.route`）。

## 已知的折衷（`success-6.png` 上看得到）

**門立在走廊裡，不是貼在牆上。**

原因：固定的 45° 俯視相機**只看得見朝南或朝上的面**。貼在南北向西牆上、
面朝東的門，畫面上是一條約 10px 的細縫（螢幕橫向輪廓 0.22，而角色直徑是 0.5）。
轉成面朝南之後是 1.58 —— 代價是它不再貼牆。

**最終方案是鋸齒狀西牆**（把門搬回牆上，而且仍然朝南），已開 `FE-W18`。
`FE-W12-S25`／`S26` 守著可見性，所以轉回去會紅。
