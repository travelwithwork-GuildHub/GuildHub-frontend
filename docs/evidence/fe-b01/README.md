# FE-B01 的瀏覽器證據

`node tests/e2e/board-panel.mjs`（需要 `npm run dev`）產生的。

## ⚠️ 這些截圖證明什麼、不證明什麼

**證明**：走到看板前按 E 開得出對應的面板（`S01`／`S02`）；面板開著時按方向鍵
WebGL 畫面的穩定差異是 **0** 個像素（`S18`）；Escape 之後面板消失、再按方向鍵
畫面差了十幾萬個像素（`S16`／`S17`）。移動的尺是 WebGL 像素，不是 DOM。

**不證明**：真的 GuildHub 後端整合可用，也**不**證明線上的 Vercel 站可用。
回應是腳本自己攔截並偽造的（`page.route`）。**不連任何團隊共用的位址。**

## 看過畫面之後的兩個備註（`design.md` 待答問題 1）

- 面板佔右側 `min(26rem, 100vw − 2rem)`、上下各留一個 gutter。1280×720 下看板與角色仍在畫面裡，沒有被蓋住。
