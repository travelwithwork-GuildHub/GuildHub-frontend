- [x] 1.3 兩條放行路徑：複製成功、或明確勾選「我已經自己保存了」
- [x] 1.4 判準：`S07`／`S08`／`S09`／`S10`（8 條）
- [x] 1.5 **突變測試：五個，一個活下來，而它逼出了第八條判準**

      | 突變 | 補強前 | 補強後 |
      |---|---|---|
      | 「進入世界」預設就可用 | 3 紅 | 3 紅 |
      | **不等寫入結果就說已複製** | **全綠 ← 活下來** | **1 紅** |
      | 寫入失敗也顯示成功 | 2 紅 | 2 紅 |
      | 拿掉勾選那條路 | 3 紅 | 3 紅 |
      | 勾了之後取消不收回 | 1 紅 | 1 紅 |

      **活下來的那個為什麼躲得過**：它的**最終狀態跟正確的版本一模一樣**
      —— 失敗時 catch 會把狀態改成 `copy-failed`。中間那一瞬間按鈕是可按的，
      而使用者可以在金鑰**沒有被複製**的情況下進去。
      補的判準用一個**永遠不 settle** 的剪貼簿把那一瞬間停住。

- [x] 2.5 **突變測試：六個，全部紅**

      | 突變 | 實測 |
      |---|---|
      | 關掉提示就記成完成 | 1 紅 |

- [x] 2.6 **端到端抓到一個單元判準抓不到的 bug**

      在世界裡走完流程之後，標題列仍然顯示「訪客」，要重整才會變。
      `IdentityProvider` 只在掛載時問一次後端，而流程建立的新身分沒有交給它。

      ⚠️ **單元判準抓不到的理由**：`IdentityBadge` 與 `FirstEntryNotice`
      在那些判準裡是**分開掛載**的，各自有一個 provider —— 所以
      「一邊變了另一邊沒變」這件事在那裡**不存在**。補的那條把它們放進
      **同一個** provider，突變（拿掉 `adopt`）紅 1 條。

- [x] 2.7 ⚠️ **修那個 bug 的過程本身值得記**：CI 紅的時候我**先修錯了東西**。
      紅的樣子是「不穩定的測試」（本機綠、CI 紅），所以我先補了等待時機。
      那個修正本身是對的，**但它讓紅燈從偶爾變成每次**，這才露出真正的原因
      —— `adopt(next)` 被突變測試之後的 `git checkout` 抹掉了，
      而 `git checkout <file>` 還原的是 **HEAD**，不是「突變之前」。
      **今天第四次犯同一個錯**，前三次當場發現，這次沒有。

## 4. 人工驗證

⚠️ **`FE-W12` 的教訓**：444 條測試全綠，而畫面上六扇門是 10 像素的細縫。

- [x] 4.1 用發表版的實際 viewport（1440×900）走完一次。
      **「同時看得見」寫成了機器答得出來的判準**：六個元素（金鑰、兩句警語、
      複製按鈕、勾選框、進入世界）的邊界框**都要在視窗內、不用捲動**。
      六條全過。

      ⚠️ **它答不出來的那一半是「讀起來清不清楚」** —— 那要人眼（4.2）。

- [x] 4.1b **截圖抓到一個 18 條斷言全綠時看不到的東西**：
      「複製鑰匙」與「進入世界」在畫面上是**兩行漂著的字**，不是按鈕。
      Tailwind 的 preflight 把 `<button>` 的預設外觀清光了。

      **這是 `FE-W12`「門看不出來是門」的同一種形狀** —— 那次也是測試全綠、
      六扇門在畫面上是 10 像素的細縫。而這一整項的重點就是「讓人真的把
      金鑰帶走」，一個沒有人認得出來的 CTA 直接摧毀它。

      補了最小可用的外觀（主要／次要按鈕、勾選列的間距）。
      ⚠️ **那不是設計系統** —— 表單與按鈕的一致性是 `FE-X05`。
      ⚠️⚠️ **`/login`（`FE-A01`，已封存）有同一個問題**，要另外處理。

- [ ] 4.2 **找一個沒看過這個專案的人走一次，不給任何提示** —— 看他有沒有把
      金鑰帶走。

      ⚠️⚠️ **這一條只有人做得到，而且兩個審查者都說它是封存的阻擋項。**
      機器答不出「他會不會停下來看」。

      codex 給的通過條件（照著做就行）：
      - 「帶走」必須是**頁面以外**可取回的 —— 不能只留在剪貼簿或還開著的頁面
      - 測試者**不能得到任何額外引導**
      - 驗證時**先關掉原頁**，再要求他把金鑰拿出來
      - **一個人走完並成功**就夠（WBS 上就是一人走查）

      ⚠️ 現在的流程已經比審查時強：**要填回金鑰最後 6 個字才進得去**，
      所以這條走查真正要看的是「**他填的時候是從哪裡看的**」——
      從還開著的畫面上抄，等於沒有帶走。
