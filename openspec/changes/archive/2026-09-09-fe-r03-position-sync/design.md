## Context

動機見 `proposal.md`〈Why〉。

**現況**：`FE-R07` 讓別人出現在畫面上，但**沒有人送自己的位置**，
所以兩個分頁互看時雙方都是靜止的。

`LocalPlayer` 的位置權威來源是 Rapier rigid body，每幀寫進 Three 的 transform，
並且**在整個生命週期裡一次都不重新渲染**。

**量到的事**：後端 `HZ = 10`；靜止時整則 `pos` 不送；
送浮點座標會讓**整則訊息被靜默丟棄**；後端**沒有 rate limit**（`BE-G16`）。

## Goals / Non-Goals

範圍見 `proposal.md`〈不做什麼〉。

**Goals**
- 讓別人看得到你在走。
- 讓「送太快／送浮點／在錯的狀態送」這三件無聲的事各自有一條會紅的測試。

**Non-Goals**
- 不決定背景頁籤的策略（`FE-R04`）。這一刀要**保留**那個決策空間，不是先做掉。

## Decisions

### D1. 專用的 ref，不重用相機的跟隨目標

`LocalPlayer` 現在已經每幀把位置寫進 `targetRef`（相機要看哪裡）。
拿它當網路同步的來源**今天是對的，之後會錯** —— 相機一旦鎖定別的東西
（觀戰、過場、鎖定目標），送出去的就變成相機在看的位置。

兩位審查者獨立給了同一個答案：**不要重用**。多一個 ref 的維護成本很低，
而且它把「可供外部消費的玩家世界位置」變成一個明確的介面。

也否決了「讓 `LocalPlayer` 自己送」：那會讓它同時負責輸入、物理、動畫、
相機與網路，而且讓它知道 transport 的存在。

### D2. `useFrame` 累積時間，不用 `setInterval`

**這個選擇的重點是它保留了什麼，不是它做了什麼。**

`setInterval` 在頁籤切到背景時**照樣會跑**，等於現在就替 `FE-R04` 決定了
「背景繼續送位置」。而 rAF 在背景會停 —— 那不是缺陷，是**如實地不做決定**：

- 前景：最多每 100 毫秒送一次
- 背景：rAF 停 → 不取樣、不送。而且**位置本來也不會變**（物理也停了）
- `FE-R04` 之後要斷線 → 在 visibility 事件上關連線
- `FE-R04` 之後要降頻 → 那時才引入可見性事件與背景計時策略

### D3. 取整之後才判斷「有沒有動」

順序是固定的，而且順序本身就是規格：

```
每幀讀世界座標 → toProtocol 取整 → 跟「上次成功送出的」比 →
不同且距上次送出 ≥100ms → 送出 → 更新「上次成功送出的」
```

**「上次成功送出的」只在真的送出去之後才更新。** 在 `ready` 之前就更新的話，
那個位置會被永遠跳過 —— 而且是無聲的。

也**不要**把 Three 的 `Vector3` 存成「上次送出」：它會被下一幀就地改寫，
比對永遠相等。存的是取整後的兩個數字。

### D4. 連線的身分就是 session generation

換 scene 時舊 client 被關掉、新的被建立。同步端如果閉包捕捉了舊的 client，
就會對一個已關閉的連線 `send` —— 而 `FE-R01` 的 `send` 在非 `ready` 會**拋錯**。

不另外做一個 generation 計數器：**client 物件的身分就是 generation**。
同步端每幀從一個共用的容器讀「目前的 client」，並在它換掉時重置節流狀態。

考慮過用 `try/catch` 包住 `send` —— **否決**。兩位審查者都指出同一件事：
吞掉那個錯誤會把生命週期的 bug 藏起來，而這一層的 bug 症狀本來就已經是無聲的。
正確的做法是**先檢查狀態**。

## Risks / Trade-offs

- **背景頁籤完全不送** → 這是 D2 刻意保留的行為。**但如果 `FE-R04` 最後決定
  「背景要降頻而不是斷線」，這一刀的取樣機制要換掉。** 那是預期內的，
  不是返工 —— 現在做 `setInterval` 才是提前上鎖。
- **極慢移動很久才送一次** → 正確行為。遠端本來就無法從整數協定分辨子像素移動。
- **「上次送出」與實際送達不同** → 我們只知道 `send` 有沒有被呼叫，
  不知道後端有沒有收到。協定沒有 ack，**這一層無法知道**。
  真正的驗證是 `FE-R09` 的 40 browser gate 與整合測試。
- **這一層驗不到「別人真的看到我動」** → 那要兩個連線。整合測試會做
  （`FE-R07` 已經有那個 harness），但**不進 CI**。
