# `FE-B09` 分享與深連結

## Why

今天面板的狀態全在記憶體：`ListPanelProvider` 的 `open`、`BoardPanel` 的 `selected`、翻頁狀態機的 `page`。
**重新整理之後全部歸零**：面板關、詳情沒了、翻頁回第 0 頁。`FE-B04` 為了「連續看很多個人才」
特別做了「返回不丟頁碼」—— 那個人手一滑重新整理，就掉回第 0 頁。

而且**沒有任何一個網址指得到「這個人」**。想把一張人才卡丟給隊友，只能說「進世界、走到人才看板、按 E、翻到第三頁、第七張」。

`FE-X01`（已封存）的 W2 子列「DOM 路由與面板開關的關係；重新整理回到同一個地方」（4 點）一直沒做 —— 這一列一起吃掉。

## What Changes

- `/world` 的 query 表示開著哪一層：`panel=profiles`、`profile=<id>`、`page=N`（第 0 頁省略）。
- 載入帶參數的網址還原同一層：清單、詳情（以 id 打 `GET /api/profiles/{id}`，`TalentDetail` 已支援沒有預覽）、頁碼。
- 互動寫回網址：開清單／開詳情各**新增一層瀏覽紀錄**；翻頁**替換**不加紀錄。
- 瀏覽器上一頁 ≡ Escape（各關一層）；深連結直達時 Escape 不離站（替換成上一層）。
- 深連結直達的頁碼已經是空的 → 退回第 0 頁、網址跟著改。不合法的參數 → canonical。
- 世界的 Canvas 在這一切期間**不重掛**。

## ⚠️ 兩輪討論談定的取捨

### 網址是 query，不是路徑段，也不是獨立頁

`/world?panel=profiles&profile=<id>`。路徑段（`/world/talent/<id>`）要保證 Canvas 不重掛得做平行／攔截路由，
超出 5＋4 點；獨立頁（`/talent/<id>`）切斷了「世界裡的 DOM 面板」這個產品模型。
兩位審查者第一輪就一致。之後案件與專案房間照同一個形狀擴充（`panel=projects&project=<id>`）。

### 上一頁 ≡ Escape，一層一個瀏覽紀錄

開清單 push、開詳情 push、翻頁 replace。上一頁與 Escape 都是「關最上層」——
`FE-X06` 剛把 Escape 定成每次只關最上層，這裡讓上一頁跟它一樣。
深連結直達時本站沒有上一層紀錄，Escape 用 replace 而不是 back，**不把人送回外站**。

### 頁碼進網址

一位審查者第一輪主張不進（「深連結分享的是實體不是第 N 頁」），第二輪收回：
「重新整理退回第 0 頁」正是這一列要消除的遺失狀態，翻頁 replace 的成本極低，
「分享出去的第 3 頁跟我看到的不一樣」在分頁瀏覽裡是可接受的副作用。
**深連結直達的頁碼已經空了 → 退回第 0 頁**：沒有「原頁」可以留，畫成「首次無資料」會讓人以為連結壞了。

### 深連結進來的人站在出生點

不把角色傳送到看板前 —— 那會新增出生位置、碰撞、鏡頭、返回位置一整套契約，
也提前侵入 `FE-W20` 留下的「3D 憑什麼存在」。面板由網址開，**不受看板互動距離限制**；
關掉之後再開，仍要走到看板前按 E。

### 首次進入流程不會攔截深連結

`/world` 對第一次來的人不導向 `/`，`FirstEntryNotice` 是世界裡的一層提示；`/` 只會把人導去 `/world`。
所以「分享網址先被首次進入流程攔截、完成後要回到原深連結」這條在今天的路由下**不會發生**，不寫成 Requirement。

## ⚠️ 不做什麼

- **SHALL NOT 做案件詳情與它的網址。** 案件那一支今天是佔位卡（`FE-B02`／`FE-B03`，W6）。
- **SHALL NOT 做專案房間的網址。** `FE-W16`（W4）。
- **SHALL NOT 做 OG 預覽圖、動態 metadata、短網址。**
- **SHALL NOT 把角色傳送到看板前，也 SHALL NOT 還原角色座標、鏡頭、捲動位置。**
- **SHALL NOT 為 SEO 建獨立的人才頁。**

## Impact

- 新增 `openspec/specs/deep-link/`
- 新增 `src/list-panel/urlState.ts`（網址 ⇄ 狀態）與掛在世界頁的同步元件
- `ListPanelProvider`／`BoardPanel`：狀態改變時寫網址；`useListPage` 接受起始頁碼、回報頁碼
- `paging.ts`：多一條「起始頁撲空 → 退回第 0 頁」
- `escapeLayers`／`ListPanel`：Escape 在深連結直達時走替換
