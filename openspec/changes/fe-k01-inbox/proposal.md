# `FE-K01` Inbox：站內信的清單、對話與寄信

## Why

站內信是陌生人**第一次正式私訊的持久紀錄**（`CONTEXT.md`：不可 Edit／Delete，防止事後抵賴）。它是那條鏈「看見 → 靠近 → 旁聽 → 打招呼 → 正式申請」上**可選的**一個落點，不是強迫所有打招呼都走這裡。
後端 `GET /api/messages`（我寄的＋我收的混在一份、`created_at` 新到舊、`page` 分頁 20 筆）與 `POST /api/messages` 早就在，契約層 `MessageOut`／`MessageCreate`
與 `operations.listMessages`／`sendMessage` 也在（`FE-A01` 第一刀為了涵蓋率），但**前端沒有任何地方能看信或寄信**。

不做會怎樣：人才看板上看到一個人、想留一句有紀錄的話，沒有地方；`listMessages`／`sendMessage` 是兩段沒有呼叫端的契約。

## What Changes

- **入口**：標題列一個按鈕「收件匣」（跟「我的名片」並列）→ 開一個阻斷式面板（`PanelShell`）；人才詳情（別人的名片）多一個「寄信給他」→ 關掉看板面板、開收件匣面板**直接進那個人的對話**。
- **對話分組**：後端給的是一份混合的扁平清單；前端以**對方**（`sender_id`／`recipient_id` 裡不是我的那個）分組成對話，每個對話顯示對方名字、最新一封的摘要與時間，依最新一封新到舊排。名字用 `GET /api/profiles/{id}` 解析（同一頁裡去重、快取），解析不到就顯示縮短的 id。
- **分頁交錯**：清單面板「載入更多」拿下一頁、以 `id` **合併**（只增不減）進已載入的信再重分組；翻到底用 `FE-X04` 的空狀態；載入更多失敗留著既有清單、可重試同一頁。對話詳情只顯示**已載入**的那些信、**沒有**自己的「載入更多」（沒有 per-conversation 端點，下一頁多半是別人的信）。每次從關閉打開重取第 0 頁。
- **寄信**：只在對話裡（回信）與從人才詳情進來（收件人已定）；沒有自由填收件人的畫面（沒有搜尋端點，`BE-G05`）。表單走 `FE-X05`（`body` 1–2000 code point，`LIMITS.messageBody`，不 trim）。**悲觀更新**：201 回來才合併進對話（依 `created_at` 重排），然後重取第 0 頁（offset 分頁被新信位移）；失敗留在表單、`FE-X05` 的 alert（404 是前端的一句、其餘 `toUiError`）。送出中可以離開（請求在 provider 裡繼續）。
- **不做未讀**（`BE-G06`：沒有寫得到 `read_at` 的端點；WBS 的裁決「沒答案就不做未讀，Inbox 只有清單與詳情」—— 那句是相對於未讀說的；`FE-K01` 的 WBS 列本來就含寄信）。
- 本地後端（`FE-O03`）補 `GET／POST /api/messages`（主體條件在 SQL 的 WHERE 裡、`no_self_send` → 400、收件人不存在 → 404、201）；契約測試（`FE-O05`）兩個目標。

## ⚠️ 討論談定的取捨

- **對話分組只在已載入的頁上**：一個對話的舊信可能在還沒載的頁 —— 這是後端分頁形狀決定的（一份混合清單、沒有 per-conversation 端點）。空狀態說的是「已載入的裡面沒有」，不假裝完整；對話裡不放「載入更多」（審查者：按了沒反應比沒有按鈕更糟）。
- **offset 分頁 ＋ 寄信會位移**：寄信成功重取第 0 頁、以 `id` 合併只增不減。別人在兩次載入之間寄來的信，下一次從關閉打開會拿到；沒有通知端點（`BE-G11`），這是能做到的最好。
- **不做自由寄信**：沒有人可以找的端點；「打招呼」的落點是人才看板（`CONTEXT.md` 的鏈）。
- **從人才詳情進來時關掉看板面板**：兩個阻斷式面板同時開會疊在同一個位置。代價：寄完信關掉收件匣只能回世界，看板的頁碼與那張卡不會自動回來（兩位審查者都點出）。**接受這個代價**：這是 MVP 的單一面板模型；「收件匣關閉後恢復看板」要一個面板堆疊，記在 Non-goals 給之後。
- **名字解析失敗不擋**：顯示縮短的 id（`1111…0001`），不阻塞清單。

## ⚠️ 不做什麼

- **SHALL NOT 做未讀／已讀**（`BE-G06`）。
- **SHALL NOT 做編輯、刪除、撤回**（後端沒有端點，`CONTEXT.md` 明寫）。
- **SHALL NOT 做自由填收件人、搜尋使用者**（`BE-G05`）。
- **SHALL NOT 做即時推送、新信通知**（`BE-G11`）。
- **SHALL NOT 做封鎖／檢舉**（`FE-T03`，W12）。
- **SHALL NOT 把收件匣放進網址**（`FE-B09` 的深連結是看板清單的；私訊不該是可分享的網址）。
- **SHALL NOT 做面板堆疊**（收件匣關閉後自動回到看板的那張卡）—— 之後要的話是一個獨立的 change。
- **SHALL NOT 在對話裡放「載入更多」**。
